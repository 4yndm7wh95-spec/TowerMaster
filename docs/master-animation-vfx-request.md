# 塔主动作与特效需求（用户补充，待 Claude 设计）

本需求属于后续开发；本地测试助手不修改 mod 代码。本轮不要直接生成动画，先由 Claude 决定方案并给出完整制作说明。

## 埋陷阱

- 所有陷阱使用同一套通用埋牌动作和特效。玩家能看出塔主埋了陷阱，但无法根据颜色、形状、音效或动作判断具体陷阱。
- 要有统一风格、质感和层次，避免廉价闪光或随意堆粒子。
- 保持陷阱身份保密；空陷阱也不能通过表现泄露。

## 出牌动作与独立特效

用户补充原话：『然后塔主出牌比如给玩家易伤 给怪物防御 这些都要做一个单独的特效 和 动作』『动作不用大幅』。

- 给玩家易伤、给怪物格挡等不同效果应各有对应的小幅动作与独立特效，不用同一个闪光替代全部行动。
- 动作应克制、短促，保留塔主统一形象；效果落点要让人看清施加对象。
- Claude 决定动作分类、哪些可以共用、动画实现方式与节奏；注意多次出牌时不遮挡怪物、手牌、血条与意图。
- 塔主形象应位于怪物后方。当前 0.0.47 仍存在有效图层高于怪物的问题，不能只看自身 ZIndex。

## 交给 imagegen 的制作说明

用户希望 Claude 先设计详细 prompt，再交本地助手生成动作帧动画；具体是否采用帧动画由 Claude 决定。

每份最终 prompt 必须自足，不能依赖助手补齐审美或动作理解。至少明确：参考形象、必须保持的细节、构图与朝向、镜头、完整动作过程、帧数和逐帧姿势、尺寸、透明背景、固定锚点、各帧一致的比例与位置、色彩材质、光效层次、哪些元素静止、哪些元素运动、禁用元素，以及与游戏背景的可读性要求。

另附不属于生图 prompt 的落地规范：文件名、帧排列或单帧输出方式、播放速度、循环/结束帧、触发时机、目标落点、图层、取消与连续播放处理、资源验收标准。优先先做少量样例验证风格和游戏内效果，再批量生成。
