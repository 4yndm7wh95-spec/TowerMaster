# 测试 3 第二轮（mod 0.0.7）

## 这一版改了什么

1. **禁止塔主手动选路**（用户要求）：塔主在地图上点任何点都没反应，日志记「塔主不能手动选路，已忽略」。塔主的票只由后台跟随爬塔玩家提交。
2. **塔主不能领东西**（设计文档「不给塔主发奖励」；开关 `test3_block_master_items`，默认开）：
   - 战斗奖励（卡牌、金币、药水、遗物）点了领不到；
   - 商店买不了，删牌也不行；
   - 宝箱遗物选不了，只能跳过。
   - 日志记「测试3 物品：塔主不能 …，已拦下」「测试3 宝箱：塔主不能拿遗物，已拦下」。
3. **奖励自动跳过不再报 ERROR**：上一轮的「not currently viewing any reward set」来自同一场里还没显示出来的奖励组，无害，现在记为「这一组奖励还没显示，不用跳过」。

## 测试步骤

注意：上一轮发现**脚本 A/B 和塔主身份反了**，实际是 B 窗口建的房。以 NetId 为准：塔主 = 100001 = 房主。

1. 两边装 0.0.7，新开一局。
2. **只操作爬塔玩家**。这一轮重点补上一轮没覆盖的：
   - **共享事件**（大家一起投票的事件）；
   - **打到第一幕 Boss 并进入第二幕**（换幕）。
3. 专门在塔主窗口试一下这些操作，确认都做不到：
   - 在地图上点一个和爬塔玩家不同的点；
   - 点战斗奖励里的卡牌和金币；
   - 商店买东西、删牌；
   - 宝箱选遗物。
4. 正常退出两个实例。

## 要检查的事项

- 每个环节爬塔玩家是否不用等塔主：选路、奖励、事件（共享、非共享）、休息处、宝箱、商店、Boss 奖励、换幕。
- 塔主手动操作是否都被拦下，日志里有没有对应的「已忽略」「已拦下」。
- 塔主的牌组、遗物、金币、药水有没有变化（应该一直是开局状态）。
- 塔主日志里有没有「测试3 …失败」ERROR。
- 共享事件：「测试3 事件：跟随玩家 … 投第 … 页选项 …」，以及最后执行的选项是否就是爬塔玩家选的。
- 换幕：「测试3 换幕：跟随玩家 … 准备」，进入第二幕后第二幕的战斗：
  - 塔主开局退场、爬塔人数 1；
  - 怪物血量记下来（第二幕没有配置混搭，是原版遭遇）。
- 塔主停在奖励或事件界面时，房间切换后画面是否正常。
- 回归：两边没有 StateDivergence；测试 1b 清单与生成一致。
