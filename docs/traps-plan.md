# 陷阱牌（mod 0.0.22）

设计见设计文档「陷阱牌」。需要 `master_turn` 开着（陷阱效果走塔主回合的联机指令通道）。

## 规则（第一版）

- **获得**：每幕第一次召唤前弹出「选陷阱包」（3 选 1）；击倒奖励（有奖励的那次）从本幕牌池抽 1 张。陷阱商店、「升级已有陷阱」「强力但有代价」后续再做。
- **陷阱包**：每幕三种风格（铁壁包：惩罚连续进攻；拖延包：拖长战斗；压迫包：怪物越打越强），每包 4 张，第二、三幕同款但等级提高、数值更强。
- **盖陷阱**：召唤面板上方「盖陷阱」区点选，每张 1 召唤点（不退），每场最多 2 张；开局保护期间不能盖。玩家只看到「塔主手里有 N 张陷阱」（第一回合开始时提示），看不到这场盖没盖、盖了什么。
- **触发**：条件满足自动触发、消耗；所有端提示「陷阱触发：名字——说明」。按单个玩家、单个回合计数，玩家类效果作用于触发者（回合类作用于所有玩家）。同名两张同一时机只触发一张。
- **没触发**：战斗胜利后翻开、收回手里，**每张没触发的陷阱给每名爬塔玩家 15 金币**（躲过奖励）。战斗没赢（全员倒下）只收回、不给奖励。空陷阱永不触发，纯诈唬，照样给躲过奖励。

| 陷阱 | 触发 | 效果（第一/二/三幕） |
|---|---|---|
| 硬化 | 玩家一回合打出第 3 张攻击牌 | 所有敌人 +5/8/11 格挡 |
| 破绽 | 玩家一回合打出第 4 张攻击牌 | 该玩家 1/2/2 层易伤 |
| 碎甲 | 玩家一回合打出第 3 张技能牌 | 该玩家 1/2/2 层脆弱 |
| 窒息 | 玩家一回合打出第 6 张牌 | 该玩家 2/2/3 层虚弱（第二幕起进压迫包） |
| 鼓舞 | 第 3 回合开始 | 所有敌人 +1/2/2 力量 |
| 狂怒 | 任意敌人死亡（还有活的） | 所有敌人 +2/3/3 力量 |
| 泥沼 | 第 2 回合开始 | 每名玩家抽牌堆塞 2/2/3 张眩晕 |
| 再生 | 第 4 回合开始 | 所有敌人回复 15/20/25% 最大生命 |
| 倒计时 | 第 6 回合开始 | 所有敌人回复 30/35/40% 最大生命 |
| 空陷阱 | 永不 | 无 |

## 实现

- 规则库：`TrapCatalog`（牌表、包）、`TrapTracker`（一场的触发判定）。
- `TrapPhase`（房主）：召唤确认时从手里拿走（`MasterLedger.TakeTraps`），战斗开始布置；回合开始（在塔主回合 begin 之前）、`Hook.AfterCardPlayed`（出牌，只算 IsFirstInSeries）、检查新死的敌人时判定；触发后发 `trap` 指令（CombatPlayPhaseOnly）。塔主回合进行中触发的先攒着，塔主回合 end 之后再发。战斗胜利发 `trap_dodge`（NonCombat，各端 `PlayerCmd.GainGold`）。
- 手里的陷阱、各幕是否选过包存在塔主账本文件里（读档继续）。
- 日志：房主「塔主陷阱：盖下…/…触发/战斗胜利，触发 N 张，没触发 M 张」；两端「塔主回合 #n …：陷阱 harden@1 触发…」「…：躲过陷阱 …每名玩家 +15 金币」「…：塔主手里有 N 张陷阱」。

## 需要实测确认

1. 选包面板、召唤面板的陷阱区（悬停看说明）、盖 2 张扣 2 点、第 3 张被拒。
2. 每种触发条件都能触发，效果两端一致，无 StateDivergence。重点：出牌钩子 `Hook.AfterCardPlayed` 是否真的找到并挂上（日志「陷阱：已挂到 …」，找不到会有 WARN）。
3. 回合开始类陷阱和塔主回合同一回合：陷阱先生效、再开塔主回合。塔主回合中触发的（理论上很少）在塔主回合结束后生效。
4. 敌人在敌方回合死亡（荆棘、中毒等）触发的狂怒：下个玩家回合开始时生效。
5. 战斗胜利后躲过奖励金币到账（两端金币一致），陷阱回到塔主手里；没赢不给。
6. 击倒奖励抽到陷阱（塔主日志「击倒奖励，获得 …」）。
7. 读档后手里陷阱还在。
