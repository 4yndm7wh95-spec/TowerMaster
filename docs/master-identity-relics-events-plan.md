# 塔主身份、塔主遗物、事件镜像：方案（0.0.43 起）

用户反馈（0.0.42 后）：
- 塔主遗物、事件/先古之民房间的塔主玩法是**必做**。
- 「随便选个角色都能当塔主」很奇怪；开战时塔主角色一闪而过、战斗结束凭空回血特效，显得潦草。

## 1. 塔主身份（不再是「某个角色」）

目标：从大厅开始到结算，任何地方都看不到「塔主是铁甲战士/静默猎手……」。

- **大厅**：房主（塔主）选角色的区域盖一块「你是塔主」面板，角色在后台固定选第一个可用角色（只为让原版能开局，所有人都看不到）；
  爬塔玩家的大厅里，房主那一格显示「塔主」而不是角色头像。
- **跑图时所有露出塔主角色的地方都藏起来或换成塔主形象**（需测试助手逐一截图确认在哪）：
  篝火（角色围坐）、商店、宝箱房、事件房、地图上的玩家标记、顶栏角色头像/名字、结算画面的角色、原版跑图历史。
- **战斗**：0.0.43 起塔主角色节点一建好就藏（不再闪）；战后不再播回血特效（直接写回生命）。

## 2. 塔主遗物（真遗物，出现在塔主的原版遗物栏）

做法和塔主牌一样：运行时生成 RelicModel 子类，用原版 RelicCmd.Obtain 给塔主；图标用自绘 PNG。各端执行同一条指令，结果一致。

来源：
- **宝箱**：塔主同时开一个「塔主宝箱」，3 选 1 塔主遗物（取代现在的「送一张牌」；遗物拿完了再退回送牌）。
- **先古之民**：见第 3 节。

第一批遗物（娱乐向，数值待平衡实测）：

| 遗物 | 效果 |
|---|---|
| 招财猫 | 每场战斗结算召唤点 +1 |
| 魔术师礼帽 | 塔主每场第一回合多抽 1 张 |
| 能量饮料 | 塔主每场第一回合能量 +1 |
| 怪物便当 | 塔主召唤的怪开场各有 3 点格挡 |
| 迷雾香炉 | 玩家信息条上的陷阱张数显示为「?」 |
| 选秀名单 | 本幕候选 Boss 变成 3 个 |
| 吝啬鬼钱包 | 玩家躲过陷阱拿到的金币减半 |
| 碰瓷护符 | 召唤的怪被打死时，给击杀者弃牌堆塞 1 张晕眩 |
| 回收站 | 每场第一张被躲过的陷阱回到塔主手里 |
| 精英会员卡 | 精英房的召唤上限再 +10% |

## 3. 事件房、先古之民房的塔主玩法（镜像）

- **先古之民**（每幕开头）：玩家选祝福时，塔主同时获得「塔主祝福」，3 选 1：一件塔主遗物 / 一张奖励池塔主牌升级 / 召唤点 +N。
  每幕开头的挑陷阱也放在这时候（现在是第一场战斗前弹出）。
- **问号事件**：玩家处理原版事件时，塔主同时抽一个「塔主事件」，界面仿原版事件（标题、配图、2–3 个选项）：

| 塔主事件 | 选项 |
|---|---|
| 黑市商人 | 花 5 召唤点买一张奖励池塔主牌 / 离开 |
| 地下赌场 | 赌一把：50% 召唤点 +6，50% −3 / 不赌 |
| 加班申请 | 下一场塔主开局能量 +1 / 手里一张陷阱升一级 / 摸鱼：召唤点 +2 |
| 怪物工会 | 下一场召唤价打 8 折 / 下一场多召 1 只免费小怪 |
| 塔主的烦恼 | 删一张塔主牌 / 复制一张塔主牌（代价：召唤点 −4） |

- **篝火**：保留现在的删牌，再加一个「升级一张陷阱」可选（二选一）。

## 实施顺序

1. 0.0.43：战斗闪现、回血特效修复；测试助手只读调研（docs/ui-043-result.md 第 7 节）。
2. 0.0.44：塔主身份（大厅 + 商店/篝火/顶栏/结算隐藏）；去掉塔主的角色遗物（燃烧之血战后回血）。
3. 0.0.45：塔主遗物框架 + 宝箱 3 选 1（第一批 8 件：招财猫、小金库、魔术师礼帽、能量饮料、怪物便当、黑名单、迷雾香炉、吝啬鬼钱包；选秀名单、碰瓷护符、回收站、精英会员卡留到下一批）；身份收尾；卡图不透明底。
4. 0.0.46：先古之民塔主祝福、塔主事件、篝火二选一。
