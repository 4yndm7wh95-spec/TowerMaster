# 测试 3：塔主全程不用操作（mod 0.0.6）

## 这一版做了什么

塔主 = 房主，全部在房主（A）自己的客户端上自动操作。用游戏原有的本地接口或动作队列提交「塔主自己的」选择，不改爬塔玩家的票。依据见 `docs/test2-round2-result.md`「测试 3 只读调研」。代码在 `mod/TowerMaster/Test3MasterAutoPilot.cs`。

| 环节 | 触发 | 塔主自动做什么 | 日志关键字 |
| --- | --- | --- | --- |
| 选路 | B 的投票执行后 | 入队一张同目的地的塔主投票；B 改票时跟着改 | 测试3 选路 |
| 战斗奖励 | 奖励集合建立后 | 跳过（塔主不领奖励） | 测试3 奖励 |
| 宝箱 | 开始选遗物后 | 跳过 | 测试3 宝箱 |
| 共享事件 | B 对某页投票后 | 投同一个选项 | 测试3 事件 |
| 休息处 | 进入休息处后 | 跳过 | 测试3 休息处 |
| 换幕 | B 准备后 | 跟着准备 | 测试3 换幕 |

**没覆盖的**：
- 非共享事件（每人各自选项）不自动选。调研结论是离开事件不等别人，B 应该能直接走。
- 商店没有全员等待，只靠选路自动投票。

## 测试步骤

1. 两边装 0.0.6。A 建房（塔主），B 加入，新开一局第一幕。
2. **只操作 B**，A 的窗口尽量不碰。尽量多经过不同房间：普通战斗、精英、事件、商店、休息处、宝箱。时间够的话打到第一幕 Boss，并进入第二幕（验证换幕）。
3. 如果某处 B 卡在「等待其他玩家」，记下是哪个环节、A 的画面停在哪。可以在 A 上手动操作一下让游戏继续，也要记下来。
4. 正常退出两个实例。

## 要检查的事项

**每个环节（看画面 + TowerMaster 日志）**
- B 是否不用等 A 就能继续：选路后直接出发、领完奖励直接走、事件、休息处、宝箱、商店离开、换幕。
- A 的日志里有对应的「测试3 …」行，有没有「测试3 …失败」ERROR。
- A 的画面：停在奖励界面、事件界面时，房间切换后是否正常跟上，有没有卡死或画面错乱。

**塔主不领东西**
- A 有没有拿到卡牌、遗物、金币、药水。可以看 A 的牌组、遗物栏、金币数。

**选路**
- 出发的目的地是否就是 B 选的点。B 改票时 A 跟着改。

**回归**
- 测试 2：塔主开局退场、爬塔人数 1、怪物血量等于单人。
- 测试 1b：清单与生成两边一致。
- 两边游戏日志没有 StateDivergence；启动没有「not associated with any mod」。
