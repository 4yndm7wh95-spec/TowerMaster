# 塔主 mod 界面规范（0.0.47 起）

用户反馈（0.0.46）：「UI 太丑，说的话难懂；节约、战果这些说法难懂，旁边直接放个数字不好看；不要太拥挤、少用文字、不要难懂的术语」。
以后所有新界面、新提示都按这几条做。

## 原则

1. **先说结果，再说原因**。画面上只放玩家这一刻要做的决定和得到的结果（「召唤点 +7」「还能花 2 点」），怎么算的放悬停提示或日志。
2. **数字配图标**。召唤点用宝石图标，陷阱用牌背图标；不写「召唤点：12」这种「标签：数字」。
3. **大白话，不用记账词**。不用：节约、战果、群体税、上限 3.9、作废、开局保护、预算花费。改成：「省下的」「怪多加价」「这场最多花 3」「多出的没存下」「前几场先手下留情」。
4. **少而短**。提示 = 一个图标 + 一行标题（结果）+ 最多一行小字；同屏最多叠 5 条，几秒淡出。没有内容就不占位（例如手里没陷阱就不显示「手里还没有陷阱」）。
5. **原版优先**。能用原版界面（手牌、选牌、遗物栏、牌组）就用原版，自建界面只做原版没有的东西。
6. **塔主不挡戏**。塔主形象画在怪物后面（ZIndex -9），半透明。

## 组件

| 组件 | 位置 | 内容 |
|---|---|---|
| 提示 `SummonPanel.ShowNotice(标题, 小字, 图标)` | 顶栏下方居中，往下排 | 收入、陷阱、遗物效果、宝箱/商店/篝火说明 |
| 信息条 `MasterInfoHud` | 顶栏下方右侧 | 牌背图标 + 手里张数；战斗中「本场」+ 每张盖下的陷阱一个小方块（触发变红）；第二行「Boss」+ 两个名字；说明全在悬停 |
| 召唤面板 `SummonPanel` | 全屏弹窗 | 左：怪物卡片（价格角标 = 宝石 + 数字）；右：「这场派谁上」账单（每只怪、怪多加价、陷阱各一行）→「这场的怪 2 / 3」进度条 →「召唤后还剩」→「召唤」 |
| 挑陷阱 `TrapDraftPanel` | 全屏弹窗 | 「还能花 N 点」「还能挑 N 张」（手里快满了才提示） |
